# 🌐 Meu Portfólio Pessoal

Este projeto é um portfólio web responsivo desenvolvido para apresentar minha trajetória, habilidades e projetos acadêmicos e pessoais na área de tecnologia. 

O site conta com recursos dinâmicos em JavaScript, como consumo de APIs públicas (geolocalização, previsão do tempo e frases do dia) e navegação entre páginas.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

* **HTML5:** Estruturação semântica das páginas (`index.html` e `projetos.html`).
* **CSS3:** Estilização moderna com Flexbox, variáveis de design e responsividade.
* **JavaScript (ES6+):** Lógica de interação, manipulação do DOM e consumo de APIs via `fetch`.
* **Git & GitHub:** Versionamento de código e gerenciamento de branches.

---

## 📂 Funcionalidades do Site

* **Cabeçalho Dinâmico:** Exibe uma saudação personalizada e um card interativo com o clima em tempo real baseado na localização do usuário, além de um gerador automático de frases motivacionais do dia.
* **Seção Sobre Mim:** Apresenta informações pessoais, objetivos profissionais e um banner horizontal moderno destacando as principais habilidades técnicas.
* **Página de Projetos:** Lista separada com os principais trabalhos e laboratórios práticos desenvolvidos (incluindo estudos em desenvolvimento web e infraestrutura em nuvem como Amazon Connect e Lex V2).
* **Formulário de Contato:** Seção estilizada em formato de card compacto com campos interativos e tratamento de envio.

---

## 🌿 Fluxo de Versionamento (Git)

Seguindo as boas práticas de desenvolvimento e os requisitos da atividade acadêmica, o projeto utiliza duas branches principais:

1. **`develop`**: Branch utilizada para a criação, testes e implementação de todas as novas funcionalidades e melhorias de layout.
2. **`main`**: Branch oficial e estável do projeto, que recebe o conteúdo da `develop` através de um processo de **Merge** após a validação do código.
